# T11: Sliders

## Goal
`drawComplexControl(CC_Slider)` draws the groove and the handle as vector shapes (handle: `Button` fill, `Dark` outline), without Fusion's cached pixmaps.

## Behaviors
- B12: given a horizontal and a vertical `QSlider`, rendered with the style, the result is no image, a groove and a handle both drawn as vector shapes (the handle filled with the palette `Button` color and outlined with the palette `Dark` color).

## Tests to write
- A horizontal `QSlider` (180x20) rendered with the style (QWidget::render on RecordingPaintDevice, SketchTheme palette, HandPaintStyle): no image, a groove shape, and a handle shape with a solid `Button` brush and a `Dark` pen.
- A vertical `QSlider` (20x180) rendered with the style (QWidget::render on RecordingPaintDevice, SketchTheme palette, HandPaintStyle): same checks.
