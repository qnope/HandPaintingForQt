# T10: Spin boxes

## Goal
`drawComplexControl(CC_SpinBox)` draws a flat frame (`Dark` outline) and up and down arrows of T3, without Fusion's cached pixmap.

## Behaviors
- B11: given a `QSpinBox` and a `QDoubleSpinBox`, rendered with the style, the result is no image, a frame outlined with the palette `Dark` color, and an up and a down arrow (B4).

## Tests to write
- A `QSpinBox` rendered with the style (QWidget::render on RecordingPaintDevice, SketchTheme palette, HandPaintStyle): no image, one outline with a `Dark` pen, one up and one down triangle.
- A `QDoubleSpinBox` rendered with the style (QWidget::render on RecordingPaintDevice, SketchTheme palette, HandPaintStyle): same checks.
