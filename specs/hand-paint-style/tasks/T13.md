# T13: apply_theme installs HandPaintStyle

## Goal
`apply_theme` installs one shared `HandPaintStyle` (instead of the plain Fusion style) on the window and its descendants; `remove_theme` restores the old styles. Update the existing tests that expect Fusion.

## Behaviors
- B15: given a `QMainWindow` with child widgets and `apply_theme(window, theme, geometry_engine)`, the result is that the window and all its existing descendant widgets use one `HandPaintStyle` (the same object for all). This replaces the "Fusion style" point of behavior B21 of `specs/sketch-paint-engine`; the other points of B21 stay.
- B16: given `remove_theme(window)` after `apply_theme`, the result is that the window and its descendants are back to the style they had before `apply_theme` (B25 of `specs/sketch-paint-engine` still holds).

## Tests to write
- A `QMainWindow` with child widgets after `apply_theme`: the window and each descendant have a style that `qobject_cast`s to `HandPaintStyle`, and it is the same object for all.
- After `remove_theme`: the window and descendants are back to the styles they had before (existing RemoveTheme tests still pass).
