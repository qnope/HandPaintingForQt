# T7: Combobox

## Goal
`drawComplexControl(CC_ComboBox)` draws a flat frame (`Dark` outline) and the down arrow of T3, for editable and non-editable comboboxes, without Fusion's cached pixmap.

## Behaviors
- B7: given a non-editable `QComboBox` and an editable `QComboBox`, rendered with the style, the result is no image, a frame outlined with the palette `Dark` color, and a down arrow (B4) drawn.

## Tests to write
- A non-editable `QComboBox` with item "A" rendered with the style (QWidget::render on RecordingPaintDevice, SketchTheme palette, HandPaintStyle): no image, one outline with a `Dark` pen, one down triangle (T3).
- An editable `QComboBox` rendered with the style (QWidget::render on RecordingPaintDevice, SketchTheme palette, HandPaintStyle): same checks.
