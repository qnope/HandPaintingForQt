# T1: vcpkg manifest and GTest from vcpkg

## Goal
Add vcpkg.json declaring gtest and replace FetchContent by find_package(GTest). The configure with the vcpkg toolchain succeeds without warning.

## Behaviors
- B1: given the repository root, `vcpkg.json` exists and declares `gtest` as a dependency.
- B2: given a configure with `-DCMAKE_TOOLCHAIN_FILE=../vcpkg/scripts/buildsystems/vcpkg.cmake`, the configure succeeds and prints no "CMake Warning".
- B3: given the CMake files of the project, none contains `FetchContent`; GoogleTest is found with `find_package(GTest)`.

## Tests to write
- vcpkg.json exists at the root and its dependencies contain gtest.
- Configure with the vcpkg toolchain exits 0 and its output has no "CMake Warning".
- No CMakeLists.txt or .cmake file of the project contains `FetchContent`; the root one contains `find_package(GTest`.
