# T4: Theme interface and Sketch palette

## Goal
Add the `hpq::Theme` interface (palette, font, rough options, fill style) with `hpq::FillStyle`, and `hpq::SketchTheme` with a complete paper / graphite `QPalette`.

## Behaviors
- B8: given `SketchTheme`, the result is a `QPalette` where every color role (`0 .. QPalette::NColorRoles - 1`) is set explicitly for each of the 3 groups Active, Inactive and Disabled.
- B9: given the `SketchTheme` palette, the result is a light "paper" `Window` / `Base` and a dark "graphite" `WindowText` / `Text` / `ButtonText`. The contrast ratio of `WindowText` against `Window` is at least 4.5 in the Active group, and lower in the Disabled group than in the Active group.
- B11: given `SketchTheme`, the result is `fill_style() == FillStyle::Solid` and `rough_options().stroke_count == 2`.

## Tests to write
- For each group Active, Inactive, Disabled and each role `0 .. NColorRoles - 1`: `palette.isBrushSet(group, role)` is true.
- `Window` and `Base` lightness > 200; `WindowText`, `Text`, `ButtonText` lightness < 80 (Active group).
- WCAG contrast ratio of `WindowText` vs `Window`: ≥ 4.5 in Active; Disabled ratio < Active ratio.
- `fill_style()` is `FillStyle::Solid`; `rough_options().stroke_count` is 2.
