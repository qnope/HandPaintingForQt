# T5: Embedded Architects Daughter font

## Goal
Embed the Architects Daughter TTF and its SIL OFL license as a Qt resource of the hpq library, register it in `QFontDatabase`, and return it from `SketchTheme::font()`.

## Behaviors
- B10: given `SketchTheme`, the result is a font whose family is "Architects Daughter". The font is embedded in the hpq library as a Qt resource (with its SIL OFL license file), and `QFontDatabase` has the family after the theme is created.

## Tests to write
- Create `SketchTheme`: `theme.font().family()` is "Architects Daughter".
- After creating `SketchTheme`: `QFontDatabase::families()` contains "Architects Daughter".
- The resource paths of the TTF and of the OFL license file exist (`QFile::exists(":/...")`).
