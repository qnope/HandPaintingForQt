# T13: Themed window paints safely and keeps input

## Goal
Check that a themed window paints offscreen with no crash, no recursion and no Qt warning, and that its child widgets still get mouse input.

## Behaviors
- B23: given a themed window shown with `QT_QPA_PLATFORM=offscreen`, the result is that it paints with no crash, no infinite recursion and no Qt warning.
- B24: given a themed window, the result is that its child widgets still get input: a mouse click on a `QCheckBox` toggles it.

## Tests to write
- Install a `qInstallMessageHandler` collecting warnings; themed `QMainWindow` with a button, a checkbox, a line edit, a table view and a graphics view; `show()`, `QTest::qWaitForWindowExposed`, `repaint()`, `grab()`: no warning collected, the test returns.
- Themed window with an unchecked `QCheckBox`, shown: `QTest::mouseClick(checkbox, Qt::LeftButton)` makes it checked.
