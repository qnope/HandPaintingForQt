# T15: Example combobox switches the Sketch theme

## Goal
In the example `MainWindow`, apply the Sketch theme at startup and connect `comboBox`: "Sketch" applies it, the two other entries remove it. Replace the example-app test of behavior B4 ("comboBox has no behavior").

## Behaviors
- B27: given the example `MainWindow` is created, the result is that `comboBox` shows "Sketch" (index 0) and the Sketch theme is applied to the window (B21 is true for it). This replaces behavior B4 of `specs/example-app` ("comboBox has no behavior").
- B28: given "China Ink" or "Black slate and chalk" is selected in `comboBox`, the result is that the theme is removed (default Qt rendering, as after `remove_theme`). Given "Sketch" is selected again, the result is that the Sketch theme is applied again.

## Tests to write
- Create `MainWindow`: `comboBox->currentIndex()` is 0, `currentText()` is "Sketch", `graphicsEffect()` is a `HandPaintEffect`, palette equals `SketchTheme` palette, font family "Architects Daughter".
- Select index 1 ("China Ink"): `graphicsEffect()` is null and the palette is no longer the Sketch palette. Same for index 2.
- Select index 1 then index 0: `graphicsEffect()` is a `HandPaintEffect` again.
- The old test asserting that the combobox has no behavior is removed.
