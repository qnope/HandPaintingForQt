# T8: Pluggable geometry engine and stable seed

## Goal
Prove that any `GeometryEngine` can be plugged into the device, and derive the seed from the primitive type and its device coordinates so the same primitive is drawn the same way twice.

## Behaviors
- B15: given a `GeometryEngine` (test fake) that returns its input unchanged, and a rectangle drawn on the device, the result is that the target receives the exact rectangle as fill and as outline. This proves a new geometry engine can be plugged in without changing the paint engine.
- B16: given the same primitive drawn twice on the device (same geometry, same transform), the result is the same rough paths both times (the seed comes from the primitive type and its device coordinates).

## Tests to write
- Identity fake engine, rect (10,10,100,50) with pen and brush: recorded fill path and every recorded stroke equal the exact rect path.
- RoughGeometryEngine, same rect drawn twice in two painting sessions: the recorded paths of both sessions are equal element by element.
- Two different rects: recorded paths differ.
