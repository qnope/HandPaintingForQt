# T7: All vector primitives go through the geometry engine

## Goal
Route every vector primitive of `HandPaintEngine` (lines, rects, ellipses, polygons in all modes, paths) through the `GeometryEngine`.

## Behaviors
- B14: given lines, rectangles, ellipses, polygons (convex, odd-even, winding, polyline) and paths drawn on the device, the result is that each one goes through the `GeometryEngine` before it reaches the target.

## Tests to write
- A spy `GeometryEngine` counting `outline()` calls and recording their input shapes. On the device draw: `drawLine`, `drawRect`, `drawEllipse`, `drawPolygon` (OddEven), `drawPolygon` (Winding), `drawConvexPolygon`, `drawPolyline`, `drawPath`: the spy sees one call per primitive, with the matching shape (bounding box equal to the drawn primitive).
- `drawPolyline` gives an open shape to the spy and no fill reaches the target.
