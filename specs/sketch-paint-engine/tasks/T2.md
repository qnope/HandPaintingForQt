# T2: Rough outline of closed and open shapes

## Goal
Extend `RoughGeometryEngine::outline()` to any `QPainterPath`: closed shapes (rectangle, ellipse, polygon, rounded rect, closed cubic path) and open curves.

## Behaviors
- B5: given a closed shape (rectangle, ellipse, polygon, rounded rect, cubic curve path), the result is `stroke_count` outline strokes. Each one starts and ends within `max_offset` of the same point (so it looks closed), and its bounding box is inside the shape's bounding box enlarged by `max_offset`.
- B7: given an open path (a cubic curve), the result is that `outline()` strokes are not closed: each starts near the path start and ends near the path end, within `max_offset`.

## Tests to write
- Parameterized over rectangle (10,10,100,50), ellipse (0,0,80,40), triangle polygon, rounded rect (0,0,100,60,12,12), closed cubic path; roughness 1, stroke_count 2, max_offset 5: 2 strokes; first and last point of each stroke within 5 of each other; each stroke bounding box inside the shape bounding box adjusted by ±5.
- Open cubic (0,0)→(100,0) with controls (30,-40),(70,40): each stroke starts within 5 of (0,0) and ends within 5 of (100,0), and its start and end are farther than 5 apart.
