# T1: Rough outline of a straight line

## Goal
Add the `hpq::GeometryEngine` interface, `hpq::RoughOptions` and `hpq::RoughGeometryEngine` with `outline()` working on a straight line path, using a seeded random generator.

## Behaviors
- B1: given the line path (0,0)→(100,0), `RoughOptions{roughness = 1, stroke_count = 2, max_offset = m}` and a seed, the result of `outline()` is exactly 2 paths. Each starts within `m` of (0,0), ends within `m` of (100,0), and has no point farther than `m` from the original segment.
- B3: given the same shape and options with two different seeds, the result is two different `outline()` paths.
- B4: given `roughness = 0`, the result is that every `outline()` stroke has the same geometry as the original shape (each point within 0.01 px).

## Tests to write
- Line (0,0)→(100,0), roughness 1, stroke_count 2, max_offset 5, seed 42: 2 paths; first point within 5 of (0,0), last point within 5 of (100,0); every element of each path is within 5 of the segment.
- Same line and options, seeds 1 and 2: the two first strokes differ in at least one point.
- Same line, roughness 0: every point of every stroke is within 0.01 px of the segment, and stroke ends match (0,0) and (100,0) within 0.01 px.
