# T12: HandPaintEffect and apply_theme

## Goal
Add `hpq::HandPaintEffect` (a `QGraphicsEffect` that draws its source through a `HandPaintDevice`) and `hpq::apply_theme(window, theme, geometry_engine)`, which sets the theme palette, font, Fusion style on the window and its descendants, and the effect.

## Behaviors
- B21: given a `QMainWindow` with child widgets and `apply_theme(window, theme, geometry_engine)`, the result is:
  - the window palette equals the theme palette;
  - the window font family is the theme font family;
  - the window and all its existing descendant widgets use the Fusion style;
  - the window's `graphicsEffect()` is a `HandPaintEffect`.
- B22: given a window with a `QFrame` box and the Fusion style and the Sketch palette, the result is that a grab of the window with `apply_theme` is not the same image as a grab with the same style and palette but no effect.

## Tests to write
- `QMainWindow` with a central widget holding a `QPushButton` and a `QCheckBox`; `apply_theme(window, SketchTheme, RoughGeometryEngine)`: `window.palette() == theme.palette()`; `window.font().family() == "Architects Daughter"`; window, button and checkbox `style()->name()` is "fusion"; `qobject_cast<HandPaintEffect*>(window.graphicsEffect())` is not null.
- Two windows 200×150 with a `QFrame` (Box, line width 2), Fusion style, Sketch palette; theme applied on one only: `grab().toImage()` of both differ.
