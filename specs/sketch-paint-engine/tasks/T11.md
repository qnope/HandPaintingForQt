# T11: Pixmaps and images forwarded unchanged

## Goal
Forward `drawPixmap`, `drawImage` and `drawTiledPixmap` from `HandPaintEngine` to the target painter without any change.

## Behaviors
- B20: given `drawPixmap`, `drawImage` or `drawTiledPixmap` on the device, the result is that the target receives the same image at the same place, unchanged.

## Tests to write
- Target: `QPainter` on a white 200×200 `QImage`. `drawImage(QPoint(20,20), img)` with a 10×10 image of 4 colors: the target pixels at (20..29, 20..29) equal the source pixels.
- Same check with `drawPixmap(QRect(50,50,10,10), pixmap)`.
- `drawTiledPixmap(QRect(0,100,40,20), 10×10 pixmap)`: every 10×10 tile of the target area equals the pixmap.
