# T10: Text drawn in the theme font

## Goal
Implement `HandPaintEngine::drawTextItem`: redraw the text on the target in the theme font, at the same pixel size, in the pen color.

## Behaviors
- B19: given a text item drawn on the device in any font (for example "Helvetica" 16), the result is that the target draws the same text in the theme font ("Architects Daughter") at the same pixel size, in the pen color.

## Tests to write
- Recording target. On the device, pen dark red, font "Helvetica" pixel size 16, `drawText(10, 30, "Hello")`: target records one text draw with text "Hello", font family "Architects Daughter", pixel size 16, pen color dark red.
- Font with point size 12 (no pixel size): recorded font has the same pixel size as the original font on this device.
