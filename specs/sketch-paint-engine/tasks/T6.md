# T6: HandPaintDevice draws a rough rectangle

## Goal
Add `hpq::HandPaintDevice` and `hpq::HandPaintEngine`: the device wraps a target `QPainter`, a theme and a geometry engine; a rectangle drawn on it reaches the target as a rough fill and rough outline strokes.

## Behaviors
- B12: given a `HandPaintDevice` that wraps a target `QPainter`, and a rectangle drawn on it with a pen and a brush, the result is that the target receives 1 fill (from `fill_area()`, in the brush color), then 2 outline strokes (in the pen color and width). None of them is the exact rectangle.
- B13: given a primitive drawn with `Qt::NoPen`, the result is that the target receives no outline stroke. Given a primitive drawn with `Qt::NoBrush`, the result is that the target receives no fill.

## Tests to write
- A test-only recording paint device/engine as target. Draw rect (10,10,100,50) with pen red 2 px and brush blue on the `HandPaintDevice` (SketchTheme, RoughGeometryEngine): target records 1 filled path in blue with no pen, then 2 stroked paths in red width 2 with no brush; none equals the exact rect path.
- Same rect with `Qt::NoPen`: only 1 fill recorded.
- Same rect with `Qt::NoBrush`: only 2 strokes recorded.
