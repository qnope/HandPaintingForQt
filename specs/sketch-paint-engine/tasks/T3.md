# T3: Rough fill area and determinism

## Goal
Add `RoughGeometryEngine::fill_area()`, a slightly deformed closed path for solid fills, and check that `outline()` and `fill_area()` depend only on shape, options and seed.

## Behaviors
- B2: given the same shape, the same options and the same seed twice, the result is the same `outline()` and `fill_area()` paths, point for point.
- B6: given a closed convex shape, the result of `fill_area()` is one closed path. Its bounding box is inside the shape's bounding box enlarged by `max_offset`, and it contains the shape's center.

## Tests to write
- Rectangle (10,10,100,50), roughness 1, max_offset 5, seed 7: `fill_area()` first point equals last point (closed); bounding box inside rect adjusted by ±5; `contains(QPointF(60,35))` is true.
- Ellipse (0,0,80,40), same options: closed, bounding box inside ±5, contains (40,20).
- Same rectangle, options and seed called twice: `outline()` results equal element by element, `fill_area()` results equal element by element.
