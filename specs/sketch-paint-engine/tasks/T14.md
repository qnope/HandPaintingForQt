# T14: remove_theme restores the window

## Goal
Add `hpq::remove_theme(window)`, which removes the effect and restores the palette, font and style saved by the first `apply_theme`.

## Behaviors
- B25: given `remove_theme(window)` after `apply_theme`, the result is that the window has no graphics effect and its palette, font and style (window and descendants) are back to their values before `apply_theme`.
- B26: given `apply_theme` called twice on the same window, the result is one `HandPaintEffect`, and `remove_theme` still restores the values from before the first call.

## Tests to write
- Window with a child button; save palette, font, window and button style names; `apply_theme` then `remove_theme`: `graphicsEffect()` is null; palette, font and the style names of the window and the button equal the saved ones.
- `apply_theme` twice: `graphicsEffect()` is a `HandPaintEffect` and the window has exactly one child of type `HandPaintEffect`; then `remove_theme`: palette, font and styles equal the values saved before the first call.
