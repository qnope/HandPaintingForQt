# T4: snake_case function names

## Goal
Rename every project function and method to `snake_case`, tests and helpers included.

## Behaviors
- B1: given the C++ code of the project, every function and method name written by the project is `snake_case` (e.g. `library_name`, `apply_default_font`, `create_table_model`, `create_tree_model`, `create_shapes_scene`); names imposed by Qt or GoogleTest (`main`, `TEST`, `Q_OBJECT`, overrides of Qt virtual functions, Qt API calls) stay unchanged.

## Tests to write
- `hpq::library_name()` returns `"hpq"` (renamed HpqTest).
- Tests call `apply_default_font`, `create_table_model`, `create_tree_model` and compile.
- A grep check finds no `camelCase` function definition left in `hpq/` and `Examples/` outside the Qt/GoogleTest names.
