# T16: Window stays usable and runs offscreen with themes

## Goal
Check that a themed window still reacts to the user, and that switching every theme in the running application gives no crash and no Qt warning.

## Behaviors
- B27: given "Black slate and chalk" is selected, when the user clicks `checkBox` and types "abc" in `lineEdit` (QTest), the result is that `checkBox` is toggled and `lineEdit` contains "abc" (the window stays usable).
- B28: given the application is started with `QT_QPA_PLATFORM=offscreen`, when each theme is selected in turn and then "None", the result is no crash and no Qt warning.

## Tests to write
- Window shown offscreen, "Black slate and chalk" selected: `QTest::mouseClick(checkBox)` toggles `checkBox`; `QTest::keyClicks(lineEdit, "abc")` makes `lineEdit->text()` "abc".
- Window shown offscreen with a Qt message handler counting warnings: select Sketch, China Ink, Black slate and chalk, None, processing events after each; no warning is recorded and the window is still visible.
