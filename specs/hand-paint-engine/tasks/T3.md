# T3: Pluggable GeometryEngine with theme colors

## Goal
Add the `hpq::GeometryEngine` interface (ideal shape in, strokes and fill area out) and let the device take one. The paint engine's `drawPolygon` and `drawPath` ask the geometry engine for the shape, then draw it on the target with the theme ink color, theme stroke width and theme fill color.

## Behaviors
- B20: given a device with a user-provided `GeometryEngine` that returns the ideal shape unchanged, when a polygon is drawn with a pen and a solid brush, the result is identical to a plain `QPainter` drawing that polygon on the theme background with the theme ink color, theme stroke width and theme fill color.

## Tests to write
- Identity geometry engine, Sketch, red pen + blue solid brush, triangle (100,30), (170,170), (30,170): the image equals a plain antialiased `QPainter` drawing on a `#FFFFFF` image of the same triangle with pen `#333333` width 1.0 and brush `#D0D0D0`.
- Same with China Ink: the image equals the plain drawing with China Ink colors and pen width 2.5.
