# T15: Theme selection applies the effect to the window

## Goal
Selecting a theme in the comboBox sets a `HandPaintEffect` with that theme on the menu bar, central widget and status bar; selecting "None" removes them.

## Behaviors
- B25: given the main window is shown offscreen, when the user selects "Sketch", "China Ink" or "Black slate and chalk" in `comboBox`, the result is that the menu bar, central widget and status bar each have a `HandPaintEffect` with the matching theme, and a grab of the window shows the theme background in an empty area of the central widget.
- B26: given a theme is selected, when the user selects "None" again, the result is that the menu bar, central widget and status bar have no graphics effect, and a grab of the window equals the grab taken at start.

## Tests to write
- For each of "Sketch", "China Ink", "Black slate and chalk": after `setCurrentIndex`, menu bar, central widget and status bar each have a `HandPaintEffect` whose theme equals the matching preset.
- After selecting "Black slate and chalk": a pixel in an empty area of the central widget in `window.grab()` is `#2F3B33`.
- Grab at start, select "Sketch", select "None": the three widgets have no effect and the new grab equals the start grab.
