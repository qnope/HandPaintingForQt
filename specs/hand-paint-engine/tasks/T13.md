# T13: HandPaintEffect

## Goal
Add `hpq::HandPaintEffect`, a `QGraphicsEffect` holding a theme: its `draw()` draws the source widget through a `HandPaintDevice` and puts the result on screen. Its theme can be changed.

## Behaviors
- B22: given the test widget of B21 (shown offscreen) with a `HandPaintEffect` set to Sketch, when the widget is grabbed with `QWidget::grab()`, the result is a hand-drawn outline of the rectangle (10,10,80,60) on the Sketch background.
- B23: given a widget with a `HandPaintEffect`, when the effect's theme is changed from Sketch to Chalk, the result is that the next grab uses the Chalk background and ink colors.

## Tests to write
- Test widget 100×80 drawing `drawRect(10,10,80,60)`, shown offscreen, `HandPaintEffect` Sketch: `grab()` gives a hand-drawn outline of the rect (10,10,80,60); pixel (50,40) is `#FFFFFF`.
- Same widget, effect theme set to Chalk: pixel (50,40) of the next grab is `#2F3B33` and the outline pixels are blends toward `#F0F0E8`.
