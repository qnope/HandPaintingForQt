# T10: Seeded randomness

## Goal
The device takes a seed (with a fixed default) used by the rough engine, so the same drawing gives the same image and another seed gives another image.

## Behaviors
- B17: given the same theme and the same seed, when the same drawing (rect + ellipse + polygon) is done twice on two devices, the result is two identical images.
- B18: given the same theme and two different seeds, when the same drawing is done, the result is two different images. A device created without a seed uses a fixed default seed, so it gives the same image every time.

## Tests to write
- Seed 42 on two devices, same rect + ellipse + polygon drawing: the two images are equal.
- Seeds 1 and 2: the two images differ.
- Two devices created without seed, same drawing: the two images are equal.
