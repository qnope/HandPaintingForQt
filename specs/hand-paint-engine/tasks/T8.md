# T8: Text, images and pixmaps pass through

## Goal
The paint engine draws text unchanged in shape but with the theme ink color, and draws images and pixmaps exactly as given.

## Behaviors
- B14: given a red pen, when `drawText(QPointF(20,100), "Hello")` is called, the result is identical to a plain `QPainter` drawing the same text with the same font on the theme background with the theme ink color (no distortion).
- B15: given a 40×40 opaque red `QImage` source, when `drawImage(QPointF(80,80), source)` is called (and the same with `drawPixmap`), the result is that the 40×40 region at (80,80) equals the source exactly.

## Tests to write
- Sketch, red pen, `drawText((20,100), "Hello")` with a fixed font: the image equals a plain `QPainter` drawing on `#FFFFFF` of the same text, same font, pen `#333333`.
- Chalk, same text: equals the plain drawing on `#2F3B33` with pen `#F0F0E8`.
- `drawImage((80,80), red 40×40)`: the region (80,80,40,40) equals the source pixel by pixel.
- `drawPixmap((80,80), red 40×40 pixmap)`: same result.
