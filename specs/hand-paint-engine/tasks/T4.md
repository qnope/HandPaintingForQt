# T4: RoughGeometryEngine draws a rough line

## Goal
Add `hpq::RoughGeometryEngine`, the default engine of the device: each straight segment becomes `passes` strokes with random end offsets and a slight bow, bounded by the theme roughness. Add the test helper that checks a "hand-drawn outline" (definition of the spec).

## Behaviors
- B5: given a red pen and `NoBrush`, when `drawLine(QPointF(20,100), QPointF(180,100))` is called on the device, the result is a hand-drawn outline of that segment, with only background and ink-blend pixels (no red).

## Tests to write
- Sketch, red pen, `drawLine((20,100),(180,100))`: every non-background pixel is within `D` of the segment.
- Same drawing: every point of the segment (sampled every pixel) has an ink-blend pixel within `D`.
- Same drawing: the image differs from a plain `QPainter` line with ink `#333333` width 1.0 on `#FFFFFF`.
- Same drawing: every pixel is a background or ink-blend pixel (no red channel above the blend).
