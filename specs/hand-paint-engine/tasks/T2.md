# T2: HandPaintDevice fills the theme background

## Goal
Add `hpq::HandPaintDevice`, a `QPaintDevice` that wraps a target `QImage` and a theme, and its `QPaintEngine`. The engine opens a `QPainter` on the target and fills the target with the theme background at `begin()`.

## Behaviors
- B4: given a `HandPaintDevice` on a 200×200 `QImage` filled red and a theme, when a `QPainter` begins and ends on the device with no drawing, the result is that every pixel of the image is a background pixel.

## Tests to write
- 200×200 image filled red, device with Sketch, `QPainter` begin/end with no drawing: every pixel is `#FFFFFF`.
- Same with Chalk: every pixel is `#2F3B33`.
- `QPainter::begin` on the device returns true and `QPainter::isActive()` is true until `end()`.
