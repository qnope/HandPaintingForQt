# T12: QWidget::render through the device

## Goal
Make `QWidget::render(&device, ...)` work: a widget's own painting reaches the hand-paint engine, at the given offset.

## Behaviors
- B21: given a test `QWidget` (100×80, at position (0,0)) whose `paintEvent` draws `drawRect(10,10,80,60)` with a pen and no brush, when `widget.render(&device, QPoint(50,50), QRegion(), QWidget::DrawChildren)` is called, the result is a hand-drawn outline of the rectangle (60,60,80,60) on the theme background.

## Tests to write
- Test widget 100×80 drawing `drawRect(10,10,80,60)`, `render(&device, QPoint(50,50), QRegion(), QWidget::DrawChildren)` on a 200×200 Sketch device: hand-drawn outline of the rect (60,60,80,60); pixel (20,20) is background.
