# T11: The three themes give different drawings

## Goal
Check that the same drawing gives a distinct result per preset, each made only of its own theme colors.

## Behaviors
- B19: given the same drawing with Sketch, China Ink and Chalk, the result is three pairwise different images, each made only of its theme's background, ink-blend and fill-blend pixels.

## Tests to write
- Same drawing (filled rect with pen + ellipse + polygon) with Sketch, China Ink and Chalk: the three images are pairwise different.
- For each theme: every pixel is a blend between the background, the ink and the fill colors of that theme (tolerance 2 per channel), with no other color.
