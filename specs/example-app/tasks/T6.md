# T6: Graphics scene with varied shapes

## Goal
Make `MainWindow` create a `QGraphicsScene` filled with varied shapes and set it on `graphicsView`.

## Behaviors
- B12: given the main window is created, the result is that `graphicsView` has a `QGraphicsScene` with at least one item of each kind: rectangle, ellipse, line, polygon, text.

## Tests to write
- `graphicsView->scene()` is not null.
- The scene items contain at least one `QGraphicsRectItem`, `QGraphicsEllipseItem`, `QGraphicsLineItem`, `QGraphicsPolygonItem` and `QGraphicsSimpleTextItem` (or `QGraphicsTextItem`).
