# T1: CMake skeleton with gtest

## Goal
Add the root `CMakeLists.txt` (C++17, Qt6, gtest via FetchContent) that builds an executable `HandPaintingExample` and a gtest executable registered in ctest, under `Examples/`.

## Behaviors
- B1: given the root `CMakeLists.txt` and Qt 6.8.3 (`CMAKE_PREFIX_PATH=$HOME/Qt/6.8.3/macos`), the result is that CMake configures and builds an executable `HandPaintingExample` (C++17) from `Examples/` plus a gtest test executable, with no error.

## Tests to write
- A trivial gtest test (`EXPECT_TRUE(true)`) is built and found by `ctest --test-dir build`.
- After configure and build, the target `HandPaintingExample` exists as a file in `build`.

## Depends on
None
