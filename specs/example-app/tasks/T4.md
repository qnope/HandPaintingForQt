# T4: Main window from the .ui with filled combobox

## Goal
Add a `MainWindow` class built from `Examples/ui/MainWindow.ui` (via AUTOUIC) whose combobox is filled with the 3 themes and has no selection behavior.

## Behaviors
- B2: given the window is built from `MainWindow.ui`, the result is that all widgets of the .ui exist unchanged (label, checkBox, lineEdit, groupBox with default texts, empty File and Edit menus, status bar).
- B3: given the main window is created, the result is that `comboBox` contains exactly 3 items, in this order: "Sketch", "China Ink", "Black slate and chalk".
- B4: given the main window is created, the result is that `comboBox` has no behavior on selection (no slot connected, nothing changes when the index changes).

## Tests to write
- Find by name: label, checkBox, lineEdit, groupBox, comboBox, tableView, treeView, graphicsView, menus File and Edit (empty), status bar; the label text is "TextLabel", the checkBox text "CheckBox", the groupBox title "GroupBox".
- comboBox count is 3 and the item texts match in order.
- Changing the comboBox current index leaves lineEdit, checkBox, label and window title unchanged, and `comboBox` has no receivers for `currentIndexChanged` (`QObject::receivers`).
