# T5: Views bound to the models

## Goal
Make `MainWindow` create the two models with the factories and set them on `tableView` and `treeView`.

## Behaviors
- B11: given the main window is created, the result is that `tableView` uses the table model and `treeView` uses the tree model, two distinct `QStandardItemModel` instances.

## Tests to write
- `tableView->model()` is a `QStandardItemModel` with 300 rows and 10 columns.
- `treeView->model()` is a `QStandardItemModel` with 20 top-level rows.
- The two model pointers are different.
